## Which apps are covered

These ship with PolyKybdHost and work as soon as it is running. Nothing to install or
configure.

Every app has a default set, drawn with `Ctrl` shortcuts. A ✓ under macOS or Linux means
the app also has its own set for that platform, which the host picks there instead (see
[Same app, different platform](/using/overlays/#same-app-different-platform)). An empty cell means that
platform gets the default set, if the app runs there at all.

Notion, Claude and ChatGPT appear twice because the desktop app and the web version are
matched separately.

Google Drive, KeePassXC and KeePass 2 need PolyKybdHost 1.18.0. Canva, Photopea, Todoist,
Google Keep, WPS Office, Telegram, Signal, League of Legends and Steam need PolyKybdHost
1.19.11. ONLYOFFICE, AutoCAD, Clip Studio Paint, CapCut, OBS Studio, foobar2000, Winamp,
GitKraken, Sourcetree, SQL Server Management Studio, Joplin, Logseq, Evernote, Everything,
Total Commander, PowerToys, Counter-Strike 2 and Dota 2 need PolyKybdHost 1.19.40.
Minecraft, StarCraft II and Warzone 2100 need PolyKybdHost 1.17.86. Civilization II and IV,
Freeciv and the Dune sets need 1.18.0; fheroes2, DevilutionX
and 0 A.D. need 1.19.11. qutebrowser, Monkeytype, keybr, IDA Pro, Binary Ninja, STM32CubeIDE,
IAR Embedded Workbench, Altium Designer, OrCAD X Capture, LabVIEW, COMSOL, Simulink, OriginPro,
Tekla Structures, SketchUp, Inventor, 3ds Max, Cinema 4D, Nuke and Substance 3D Painter need
PolyKybdHost 1.19.58. Maya, Houdini, QGIS, Mathcad Prime and Pro Tools need 1.21.0. Cubase,
Bitwig Studio, Ardour, LMMS, Logic Pro, GarageBand, AniCraft, TextureCraft and MaterialCraft
need 1.22.16.

In Age of Empires II the letter keys build, train and give orders, and their meaning changes with
the selection, so only keys that always do the same thing have icons. Each digit shows a different
unit as a group (spearmen on 1, archers on 2, cavalry on 3 and so on): the bare digit selects the
group, and with Ctrl, where the icon has a plus, it creates it. The game does not tie a group
number to a unit type; the icons only suggest a habit. The Esc mark is drawn without the key legend
from firmware 1.9.15; the control groups and the Definitive Edition set need PolyKybdHost 1.17.82.

Claude Code, Codex CLI, Gemini CLI, GitHub Copilot CLI, OpenCode, Qwen Code and Aider need
**PolyKybdHost 1.19.11**. The other terminal programs, kitty, WezTerm, tmux and Zellij need
**PolyKybdHost 1.19.58**. GDB's second set, for a running program, needs **PolyKybdHost 1.20.0**. The emulators need **PolyKybdHost 1.20.0**. Their keycap lettering needs firmware 1.10.2 to sit
in the top-left corner; older firmware draws it centred.

Team Fortress 2, Apex Legends, Path of Exile, Path of Exile 2, Rocket League, Overwatch 2 and
Genshin Impact need **PolyKybdHost 1.27.6**. None of these sets was checked on an installed copy
of the game: the process names and the key files come from the games' depot listings and from
players' published config files.

The games in the rows from Battle for Wesnoth to osu!, and the emulators and ports
ScummVM, PPSSPP, Dolphin, PCSX2, DuckStation, OpenGOAL, Ship of Harkinian, sm64ex and
sm64coopdx need **PolyKybdHost 1.25.10**. None of these sets was checked on an installed copy of
the game: the process names come from each project's build files.

Firefox, Blender, the ArtCraft apps (except AniCraft, TextureCraft and MaterialCraft), Cursor,
Windsurf, Zed, LM Studio and Jan need
**PolyKybdHost 1.17.18 or later**. The games, the three slicers, Eclipse, Arduino IDE 2, Ghidra,
Wireshark, Trello, Figma on the web, YouTube, Vim, Emacs and nano need **PolyKybdHost 1.17.82 or
later**.

<Aside type="note">
This is what ships today. The authoritative list is `overlay-mapping.poly.yaml` in
PolyKybdHost. Adding an app yourself is a template image plus one mapping entry.
</Aside>

<Aside type="tip">
**An app that is not listed no longer shows blank keys.** PolyKybd collects what it can by
itself: the app's own icon on Escape, and an icon on each shortcut the app publishes. See
[Apps With No Overlay](/using/generic-overlays/).
</Aside>

<Aside type="note">
The icons for the operating system's own shortcuts, such as Win+L or Cmd+Tab, are not part of an
app overlay. The firmware draws them for every app. See [Shortcut Hints](/using/shortcut-hints/).
</Aside>
