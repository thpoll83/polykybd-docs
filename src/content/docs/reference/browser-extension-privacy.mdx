_Last updated: 2026-11-13 (extension version 1.1.0)_

This is the privacy policy for the **PolyKybd Website Reporter** browser extension, which
helps [PolyKybdHost](/software/overview/) show [website-specific keycap overlays](/using/website-detection/).
It describes exactly what the extension accesses and where that data goes.

## What it accesses

- The **URL** and **title** of your **currently active browser tab**.
- Whether the browser window is **focused**.
- Since version 1.1.0, only when PolyKybdHost asks it to switch to a Claude Code cloud session
  (you pressed that session's agent key on the keyboard): the **URLs of your open tabs**. The
  extension compares them, inside the browser, with the one session address
  (`https://claude.ai/code/session_…`) that PolyKybdHost sent. The other tabs' URLs are not
  sent anywhere. It then activates that tab and focuses its window. Its answer to
  PolyKybdHost says whether it found the tab and gives that tab's title. Because the tab is
  now the active one, the usual active-tab report (its URL and title) follows, as after any
  tab switch.

It does **not** read page content, form data, cookies or history. It sends a report when the
browser starts, when the extension is installed, and on tab switches, navigation and
window-focus changes. It never opens a page.

## Where the data goes

- Reports are sent **only to `http://127.0.0.1` (localhost)** — the PolyKybdHost application
  running on the **same computer**.
- **Nothing is transmitted over the internet.** The data is not sent to the developer, to
  PolyKybd / PolyTasten, or to any third party.
- The data is used only at that moment to pick the matching keyboard overlay, or to switch to
  the tab PolyKybdHost asked for. The extension does not log or retain your browsing activity.

## What it stores

- Only your **settings** — the host port and an optional token — saved with the browser's
  extension storage on your device. No browsing data is stored.

## Data sharing / selling

None. The extension does not sell data and does not share it with anyone.

<Aside type="note">
Under both Chrome and Mozilla policies, active-tab URLs are classified as **web browsing
activity**. The extension collects it only for the website-aware overlay feature and the agent
keys, and transmits it only to the local PolyKybdHost app.
</Aside>
