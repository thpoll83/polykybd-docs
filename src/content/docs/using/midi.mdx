The PolyKybd is also a USB MIDI device. On its MIDI layer the keys send notes and controls
to a music program (a DAW such as Ableton Live, Logic Pro, Reaper or Bitwig, or a software
synthesizer), and every keycap shows what it plays: the note name with its octave and the
note on a treble staff.

![The MIDI layer on a split72. The left home row plays C4 to G4 with the black keys above it, the right half continues from A4 to F5. The outer keys hold All Off, the sustain pedal, legato and the channel, the number row has pitch bend, modulation and the channel keys, and the right number row has the dynamics marks pp to ff](../../../assets/using/midi-layer.png)

<Aside type="caution" title="Updating from 1.11 or older resets the keymap and macros once">
The MIDI layer is stored with the other remappable layers, so the stored keymap changes
format. On the first start after the update, the keyboard resets your remaps **and deletes
your macros**. Write down your remaps and macro texts before you update, and enter them
again after it. Later updates keep them.
</Aside>

## Open and leave the layer

On split72 with firmware 1.13.4 or later, hold **Fn** and press the key above the right
Shift (`\` on a QWERTY layout). On the first start of 1.13.4, a keyboard that already
stored a keymap gets this key on its Fn layer too, unless you had changed that key on the
Fn layer before.

The Utility layer also opens the MIDI layer:

1. Hold **Fn** and tap **Util** (the top-left key of the Fn layer) to open the Utility layer
   for one key press.
2. Tap **MIDI**. Since firmware 1.13.2 it is in the right half's outer column, directly
   under the settings key.

   Firmware 1.13.0 put this key at the start of the media row on the right half, with a
   treble clef on it. A keyboard that ran 1.13.0 keeps the key there after an update,
   because the Utility layer is part of the stored keymap. The key then reads **MIDI**.
   To move it, use **Reset keymap to default…** in PolyKybdHost, which also deletes your
   macros, or move it in the [Keymap Editor](/using/keymap-editor/).

The keyboard stays on the MIDI layer until you press **Base** (bottom left), which returns
to your base layer.

## Play notes

The keys are laid out like the computer-keyboard mode of Ableton Live and Logic Pro: the
home row plays the white keys from **C4** (middle C) upwards, and the row above it plays the
black keys. Blank keys are the gaps between the black keys, and they send nothing. On
split72 the left half plays C4 to G4 and the right half continues from A4 to F5. The split42
has the same piano on its main keys, with the pedals on the thumbs.

A note keycap shows the note it plays now. When you change the octave or transpose, every
note keycap changes to the new note. Past the top or bottom of the MIDI range a note wraps
to the other end, and its keycap shows the note that is sent.

## The control keys

| Keycap | What it does |
|---|---|
| **OCT** with *8vb* / *8va* | One octave down or up. The keycap shows the current octave. |
| **OCT** with a number | Sets that octave for the `C` key directly. **OCT 4** puts middle C on the home row again. |
| **TRNS** with ♭ / ♯ | Transposes one semitone down or up. The keycap shows the current transposition. |
| **VEL** with > / < | Lowers or raises the velocity (how hard each note is played). The knob does the same. |
| **pp** to **ff** | Sets a fixed velocity: pp, p, mp, mf, f, ff. |
| **CHAN − 1** / **CHAN + 1** | Changes the MIDI channel (1–16). The keycap shows the current channel. |
| **Ped.** | Sustain pedal, while held. |
| **Sost.** | Sostenuto pedal, while held. |
| **u.c.** | Soft pedal (*una corda*), while held. |
| **LEG** | Legato, while held. |
| **PORT** | Portamento, while held. |
| **MOD** | Modulation wheel, while held. **MOD spd − / +** sets how fast it moves. |
| **BEND** | Pitch bend down or up, while held. |
| **All Off** | Stops every sounding note. |

Changing the channel first stops the notes and releases the pedals, the bend and the
modulation on the old channel, so nothing stays on there.

The octave, transposition, velocity and channel are reset when the keyboard starts: middle C
on the home row, velocity 127, channel 1.

## Use it in a music program

The keyboard appears as a MIDI input device under its own name, next to its keyboard and
mouse functions. No driver or host software is needed. Select it as the MIDI input in your
program, open the MIDI layer and play.

The keyboard only sends MIDI. It does not receive anything from the computer, so a program
cannot change its keycaps, lights or settings over MIDI.

## First-time guide

<SupportedSince label="Firmware 1.13.4+, PolyKybdHost 1.22.16+" title="Minimum firmware and PolyKybdHost versions this feature needs" note="split72" />

The first time a music program that takes MIDI input is in front, the keycaps show how to
open the MIDI layer. The focus ripple runs on **Fn**. While you hold Fn, it moves to the key
that opens the MIDI layer, and when you let go of Fn it moves back. It stops when the MIDI
layer opens, after about 30 seconds (12 ripples, 2.5 seconds apart), or when the program is
no longer in front.

The guide follows the keymap stored on the keyboard. If you moved Fn or the MIDI key in
the [Keymap Editor](/using/keymap-editor/), it shows your keys. It needs a path of at most
four layer keys from your base layer to the MIDI layer; without one, there is no guide.

Each program gets the guide once. A web page counts by its site: each site below gets it
once, whichever browser it is open in.

| | Programs and sites |
|---|---|
| **Programs** | Ableton Live, Ardour, Bitwig Studio, Cubase, FL Studio, GarageBand, LMMS, Logic Pro, MuseScore, Pro Tools, REAPER, SoundCraft |
| **Web pages** | Ableton Learning Synths, AI Duet, Amped Studio, Audiotool, BandLab Studio, Chrome Music Lab (Shared Piano, Song Maker), Flat, flowkey, Hookpad, musictheory.net exercises, muted.io piano, Noteflight, Online Sequencer, Patatap (with `?midi` in the address), Recursive Arts Virtual Piano, Sight Reading Trainer, Signal, Soundation, Soundtrap, Teoria exercises, Virtual Piano |

<Aside type="note" title="Safari">
Safari does not support Web MIDI, so these web pages cannot receive the keyboard's notes in
Safari, and the guide does not run there.
</Aside>

To see the guide again, run `polyctl attention --midi` (see [polyctl](/software/cli/)). With
`--reset`, every program and site gets the guide again the next time it is in front. The
host keeps the list of programs and sites that had the guide in `midi_guide_seen.json`, in
the same folder as `settings.yaml`:

| Platform | Folder |
|---|---|
| Windows | `%LOCALAPPDATA%\PolyHost\PolyHost\` |
| macOS | `~/Library/Application Support/PolyHost/` |
| Linux | `~/.config/PolyHost/` |

## Change the layer

The MIDI layer is one of the nine layers you can remap in the
[Keymap Editor](/using/keymap-editor/). The keycode browser lists every MIDI keycode under
**Midi**: notes over six octaves, the octave, transpose, velocity and channel keys, and the
pedals and controls above. Any MIDI key you put on another layer works there too, and shows
the same legend.
